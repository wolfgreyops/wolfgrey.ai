What an agent needs

Three things, and none of them is design.

An agent does not browse. It fetches a page, looks for facts it can trust, and tries to finish a task. It can take in a website quickly when three things are true.

01

Text it can fetch

The words are in the page itself, under clear headings. Nothing important is locked inside an image, an animation or a script.

02

Facts it can trust

Who you are, what you do, where and when, stated plainly and repeated as structured data that matches what the page says.

03

Actions it can finish

Booking, quote and contact forms with labeled fields and no dead ends, and no bot wall in front of a customer's agent.

      Agent view

      This page, in the order an agent reads it.

      An agent does not see a design. It works through a page in six steps, and each step depends on the one before. Everything shown for each step is read from this page's own markup.

      1. 01Text it can fetch

        Can it get in?

        The first request decides everything. If robots.txt turns the agent away, the page returns an error, or a bot wall answers instead, the visit ends here and nothing below is read.

      2. 02Text it can fetch

        What is this page?

        Next it reads the title and the description. A search engine lists them, and an assistant uses them to decide whether the page is worth opening, so they should say plainly what the page is and who it is for.

      3. 03Text it can fetch

        How is it organized?

        Headings are the map. An agent skims them to find the part that answers the question it was sent with. One clear top heading and plain section headings do more here than any styling.

      4. 04Text it can fetch

        What does it say?

        Then it reads the sentences. This is all it can quote or repeat to a customer. Words that sit inside an image, an animation or a script that has to run first usually never reach it.

        Read the full text
      5. 05Facts it can trust

        Which facts can it trust?

        Structured data states who you are and what you offer in a format made for machines. An agent leans on it when it matches the page text, and discounts it when the two disagree.

        Read from the structured data in this page. Every line is also stated in the text.

      6. 06Actions it can finish

        What can it do next?

        A visit pays off only when the agent can act: follow a link or complete a form. Labeled fields tell it what to enter. An unlabeled field, a dead end or a CAPTCHA stops it.
