The conversational interface for research, writing, and thinking

Claude Code

Anthropic's agentic coding tool that lives in your terminal

Claude Code is a game-changer. It's an AI coding agent that can read your codebase, make changes across multiple files, run commands, and iterate on its own work. Unlike chat-based coding assistants, it actually does the work.

  • Full codebase awareness — It reads and understands your entire project, not just the file you're looking at
  • Multi-file edits — Makes coordinated changes across multiple files in a single operation
  • Terminal access — Runs tests, installs packages, commits code, and executes commands
  • Agentic loops — Can work autonomously, trying approaches, checking results, and iterating

We use Claude Code to build client automations, create internal tools, maintain this website, and prototype new ideas. It's like having a senior developer who never gets tired.

Model Context Protocol (MCP)

The open standard that connects Claude to external tools and data

MCP is how we give Claude superpowers. It's an open protocol that lets Claude connect to databases, APIs, file systems, and other tools securely. Think of it as USB for AI.

  • Supabase integration — Claude can query and modify databases directly
  • Browser automation — Control Chrome to scrape data, fill forms, or test interfaces
  • File system access — Read and write files, manage projects, organize data
  • Custom tools — Build bespoke integrations for specific client needs

MCP is what makes our AI agents actually useful. Without it, Claude is just a chatbot. With it, Claude becomes a capable assistant that can take real actions.
