# wolfgrey Newsletter Creation

## When to Use This Skill

Use for creating:
- Weekly newsletters from X posts
- Standalone Substack articles
- Email campaign content
- Weekly digest compilations

## Newsletter Structure

### 1. Title & Header
```
# The Weekly Build | [Month Day, Year]

---

**This week: [2-3 topic teases, comma separated]**

---
```

### 2. Opening Hook (1-2 sentences)
- Set the theme for the week
- Make a bold claim or observation
- Create curiosity

### 3. Main Sections (2-4 sections)
Each section:
- **Section header** (##)
- Expand on a key topic from the week's posts
- Add context not in the original tweet
- Include specific examples
- 150-250 words per section

### 4. Quick Hits
Bullet points of smaller insights:
```
## Quick Hits

**[Bold topic sentence.]** [1-2 sentence expansion]

**[Bold topic sentence.]** [1-2 sentence expansion]

**[Bold topic sentence.]** [1-2 sentence expansion]
```

### 5. One Thing to Try
Actionable takeaway readers can implement immediately:
```
## One Thing to Try This Week

[Specific, actionable task]

[Why it matters]

[Expected outcome]
```

### 6. CTA Section
```
---

**Want [specific resource]?**

[What they'll get]

[**wolfgrey.ai/resources**](https://wolfgrey.ai/resources)

---

*Built with Claude. Shipped by wolfgrey.*
```

## Writing Guidelines

### Voice
- Direct, operator-to-operator
- Write like you're emailing a smart friend
- Conversational but professional
- Results-first, no fluff

### Length
- Total newsletter: 500-800 words
- Main sections: 150-250 words each
- Quick hits: 1-2 sentences each
- Keep it scannable

### Expanding Tweets into Sections

When converting tweets to newsletter sections:

1. **Start with the tweet's core idea**
2. **Add the "why"** — Why does this matter?
3. **Add the "how"** — How do you actually do this?
4. **Add an example** — Make it concrete
5. **Add the result** — What happens when you do this?

**Example:**

Original tweet:
```
Most businesses use AI like a search engine.
The real unlock: treating it like a junior employee.
Assign tasks. Review work. Give feedback.
```

Expanded section:
```
## The Shift Nobody's Talking About

Most people still think AI means chatbots. Ask a question, get an answer, do the thing yourself.

That model is already outdated.

The real shift is from **chatbot** to **agent team**:

- **Chatbot**: You ask, it answers, you act.
- **Agent team**: You assign, they coordinate, you review.

One keeps you in the loop on every task. The other keeps you in the loop on results.

Here's the framework we use to know when a workflow is ready for this shift:

1. **Delegation** — Can you hand it off entirely?
2. **Description** — Can you define the task clearly?
3. **Discernment** — Does AI know when to ask for help?
4. **Diligence** — Are there guardrails for mistakes?

If a workflow fails one of these, it's not ready to automate.
```

## Section Ideas by Theme

### ROI/Results → "Real Workflows, Real Time Saved"
- Lead with specific numbers
- Walk through the before/after
- Name the business type

### Tactical Tips → "How To" or "The Trick"
- Step-by-step instructions
- Copy-paste examples
- Common mistakes to avoid

### Mindset Shifts → "The Shift" or "What Most People Get Wrong"
- Contrast old thinking vs new
- Explain the reframe
- Give specific application

### Tool/Workflow → "Workflow of the Week"
- Name the workflow
- List the steps
- Show the outcome

## Formatting Rules

1. **Use horizontal rules** (`---`) to separate major sections
2. **Bold key phrases** for scannability
3. **Use bullet points** for lists
4. **Keep paragraphs short** — 2-3 sentences max
5. **Include links** where relevant
6. **Always end with CTA** to wolfgrey.ai/resources

## Compiling from X Posts

When given a week's worth of X posts:

1. **Identify themes** — Group posts by topic
2. **Select 2-4 strongest** — Pick posts with the most value
3. **Expand, don't copy** — Add context and depth
4. **Create Quick Hits** — Use remaining posts as bullet points
5. **Find the thread** — What connects this week's content?
6. **Write the hook** — Tease the main themes

## Subject Lines

Keep subject lines:
- Under 50 characters
- Specific and curiosity-driven
- No clickbait

Examples:
- "The 10-hour mistake"
- "Why your prompts fail"
- "AI isn't a search engine"
- "The workflow that saves 6 hours"
